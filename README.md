# Crot Tok

Личный твик для TikTok (Theos, iOS 14+). Подключается только к com.zhiliaoapp.musically.
Внутри TikTok появляется плавающий питомец Крот. Нажми на него: откроется панель в стиле Material You.

## Что умеет
- подмена региона: оператор SIM и региональные настройки (применяется после перезапуска)
- питомец Крот: сытость, настроение, печеньки (+1 за каждые 10 видео)
- 10 функций: автолистание, не гасить экран, тёплый фильтр, напоминание об отдыхе,
  статистика, вибро при листании, блокировка ленты, приглушение яркости, чистые ссылки, очистка кэша
- 8 акцентных цветов

## Сборка
Actions -> Build CrotTok -> Run workflow. В артефакте два .deb: iphoneos-arm (rootful) и iphoneos-arm64 (rootless).

## Важно
- Если TikTok установлен с другим bundle id (подписанная копия), поменяй его в CrotTok.plist.
- Скрытые классы TikTok не используются, поэтому твик переживает обновления приложения.
- Подмена региона может не изменить ленту: сервер смотрит ещё на IP и аккаунт.
- Модификация TikTok нарушает его правила использования. Аккаунт могут ограничить.
