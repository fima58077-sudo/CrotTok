# Crot Tok 2.0

Твик для TikTok (Theos, iOS 14+, arm64 и arm64e). Подключается только к `com.zhiliaoapp.musically`.

## Где настройки
- В настройках TikTok CrotTok пытается добавить карточку «CrotTok» (находит экран по его содержимому).
- Запасной вход: нажми на питомца и выбери «Настройки» (или зажми питомца).

## Категории
- Сеть: подмена региона, выбор страны.
- Оформление: тема Material You, акцентный цвет (палитра, HEX, предпросмотр, сброс), форма аватарки.
- Рофлы: скример (выключен по умолчанию, интервал 5 минут).
- Основное: Крот, автолистание, экран, фильтр, отдых, вибро, блокировка ленты, яркость, чистые ссылки, кэш, диагностика, сброс.

## Что делает «Material You во всём TikTok»
Акцент и стили применяются к стандартным элементам UIKit: окна, переключатели, ползунки, индикаторы,
поля ввода, всплывающие окна и меню. Собственные элементы TikTok (лента, нижняя панель, профиль)
нарисованы его собственными классами. Чтобы перекрасить их, нужны их названия:
открой нужный экран, вызови «Диагностика экрана» и пришли скопированный текст.

## Форма аватарки
Применяется ко всем круглым картинкам нужного размера, которые находит CrotTok. Возможны ложные срабатывания
(например, круглые кнопки с картинкой). Капсула на квадратной аватарке выглядит как круг.

## Сборка
Actions -> Build CrotTok -> Run workflow. В артефакте два .deb: rootful (iphoneos-arm) и rootless (iphoneos-arm64).

## Важно
- Подмена региона меняет сигналы SIM и региональных настроек. Лента и аккаунт зависят ещё от IP.
- Скример: тихий звук системным каналом (уважает беззвучный режим), без вспышек, закрывается касанием.
- Модификация TikTok нарушает его правила. Аккаунт могут ограничить.
